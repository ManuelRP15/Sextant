# Contributing

Thank you for looking. This repository is Sextant's public home — its documentation, policies and release records — not its source code, and it does not take pull requests. What it does take:

- **Bug reports and feature requests**, as issues. [SUPPORT.md](SUPPORT.md) says what helps and what must never be pasted.
- **Reproductions in the interactive demo.** The demo at https://usesextant.dev/demo/ runs the real product against a fictional org, so a step-by-step reproduction there carries no real data and can be followed exactly.
- **Documentation feedback**: an unclear sentence, a wrong claim, a broken link. Say which file and which line.
- **Security reports**, privately, through [SECURITY.md](SECURITY.md). Never a public issue, never with a real session id or org data.

## Why the source is not here

Whether and under what terms Sextant's source is published is a decision that has not been made yet. Until it is, this repository is deliberately honest about what it contains: what the product says about itself and the evidence for it, versioned with the product. If that changes, the source will be published here or linked from here, with its licence stated plainly.
